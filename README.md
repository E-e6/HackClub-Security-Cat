Hack Cat Security 🐱🔒

An interactive 2-page website that teaches users about digital security in a fun and playful way. Featuring JavaScript animations, Tailwind CSS styling, and quirky cat-themed interactions to make learning cybersecurity engaging.

🌐 Live Demo: Hack Cat Security

📂 Project Structure
Hack-Cat-Security/
│── index.html       # Main landing page with interactive content
│── about.html       # About page explaining project goals
│── /assets          # Images, icons, and media files
│── /css             # Tailwind CSS or custom styles
│── /js              # JavaScript for animations & interactions
│── README.md        # Documentation (this file)

🚀 Features

🐱 Cat-Themed Security Lessons – playful visuals to explain cybersecurity basics

🔒 Interactive Elements – hover animations, click events, and quizzes

🎨 Tailwind CSS Styling – clean, modern design with responsive layout

⚡ JavaScript Animations – adds movement and fun effects

📱 Responsive Design – works on desktop, tablet, and mobile

🛠️ Getting Started
1. Clone the Repository
git clone https://github.com/yourusername/hack-cat-security.git
cd hack-cat-security

2. Open the Website

Since this is a static project (HTML, CSS, JS only),

Open index.html → main page

Open about.html → about page

Or use VS Code Live Server for local development:

# Install VS Code Live Server extension
# Right-click index.html -> "Open with Live Server"

🎨 Development Notes

Styling: Built with Tailwind CSS

Animations: All animations are powered by vanilla JavaScript in /js.

Images: Cat images/icons are in /assets.
How to Use

Open the website and start on the Home Page (index.html)

Hover over the cat icons for fun animations

Click buttons to reveal cybersecurity tips

Visit the About Page (about.html)

Learn about the project’s purpose

Explore links to cybersecurity resources
